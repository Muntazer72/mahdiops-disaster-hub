## 🚀 Project Overview
A rapid-response emergency humanitarian logistics and ground coordination platform deployed on an AWS EC2 Ubuntu instance. Designed for chaotic post-disaster scenarios where global communication channels fail, this app processes multi-modal inputs (damaged infrastructure images, field reports, and voice/text logs) to auto-generate actionable operational rescue summaries.

---

## 🛠️ Unified Challenge Matrix Integration (4 Mandatory Tracks)

1. **Google Gemma 4 Core (Gemini API Integration):**
   - Utilizes Google's generative multimodal models (`gemini-1.5-flash` / Gemma endpoints) via Flask to analyze uploaded field imagery (e.g., washed-out transit corridors, damaged bridges) and instantly evaluate structural threat levels and rescue priorities.

2. **Snowflake CoCo Data (Infrastructure & Mock Queries):**
   - Integrates structured regional baseline data and topographical metrics simulating Snowflake marketplace queries to map crisis areas against baseline city infrastructure.

3. **Solana Agent Registry (Onchain Identity Simulation):**
   - Implements core triage automation scripts simulating verifiable onchain registration and uptime diagnostics on the Solana Agent Registry for trusted international agency verification.

4. **GitHub Copilot Acceleration:**
   - Leveraged GitHub Copilot chat layouts and autocomplete to rapidly prototype Flask routing logic, bootstrap the SQLite/in-memory data handlers, and squash syntax issues under strict hackathon time constraints.
